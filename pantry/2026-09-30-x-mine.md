# X mine: Claude Code Game Dev competitors

## How this fills

1. Take the top 5 to 8 names from the latest competitor map.
2. Search X for praise and complaints tied to **named matrix capabilities** (reliability, cost, DX, permissions, memory, multi-agent, verify), not brand vibes alone.
3. Fetch primary posts; quote short snippets with `x.com` links. **Never invent engagement counts or sentiment %.**
4. Save as `YYYY-MM-DD-x-mine.md` (keep this TEMPLATE).

Every snippet below is verbatim text of the post, fetched on 2026-09-30 through `https://api.fxtwitter.com/status/<id>` (x.com itself answered HTTP 402 to a direct fetch). No complaints were found, but X search itself was not available this run (see the log), so that is not evidence that there are none.

## Search log (what we tried)

- WebSearch was unavailable for X: the session's shared budget was used up (200 of 200 calls) before any X query ran. Refused queries: `site:x.com "unity-mcp"`, `site:x.com "godot mcp" claude`, `site:x.com "claude code" godot`, `site:x.com "claude code" unity`, `site:x.com "Claude Code Game Studios"`, `site:x.com blender mcp claude`, `site:x.com "claude code" "game dev"`, and a second try of `site:x.com "claude code" godot`. The plain (no `site:`) X queries were not run for the same reason. No other search engine was used to route around the limit.
- Post IDs came from x.com links inside competitor READMEs and GitHub-hosted newsletter digests, found with GitHub code search (`gh api search/code`), 11 searches, about 16 digest files read.
- Direct fetch of x.com status pages: HTTP 402 on all 3 tries.
- `api.fxtwitter.com/status/<id>`: 14 post IDs fetched, all HTTP 200. 7 were on topic and 6 are kept above; the seventh, a second @unitygames post about the profiler, was dropped as a duplicate theme. Two were named off topic (one about Unity's stock price, one about image-layer research).
- GitHub issue search for `"x.com"` across 9 competitor repos: 1 result, an unrelated pull request.
- Each kept snippet was fetched again through fxtwitter before it was written here, and matched.
