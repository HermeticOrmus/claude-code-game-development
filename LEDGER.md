# Kintsugi ledger: claude-code-game-development

Kintsugi mends a broken bowl with gold, so the repair is the part you look at. Here it means every crack we find in this pack is written down with its evidence, sealed with a fix you can check, and kept in this table instead of being patched quietly.

The hallmarked rows shipped in [v2.0.0](https://github.com/HermeticOrmus/claude-code-game-development/releases/tag/v2.0.0) through [#2](https://github.com/HermeticOrmus/claude-code-game-development/pull/2), which was verified by installing every plugin from GitHub into a clean config. For this ledger the released pack was installed from GitHub into a clean Claude Code config again: 87 of 87 plugins enabled. Sealed rows are fixed in an open pull request; open rows are cracks the repo already tracks, and the Tracker column says where to pick one up.

Grades: **hairline** is copy or cosmetic, **fracture** is wrong behavior with a workaround, **break** means it did not work or broke a safety promise.
